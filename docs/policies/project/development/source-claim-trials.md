# Source Claim Trial Status

The source-claim extraction/binding, synthetic assessment and reported-state Python tools are **retired**. They are unavailable in the current checkout and
have no replacement research command. This page routes retained design and
history; it is not an execution procedure.

## Operations

The [Source Claims And Work State contract](../source-claims-and-work-state.md) retains the normative source, protocol,
admission and assessment rules. The [complete former procedures](../../../plans/research/retired-python-research-tools.md#source-claim-trials)
preserve every prior command condition, bound, replay rule and evidence limit,
under an explicit historical/unavailable status.

Conditional binding and end-to-end extraction remain different evidence. No private-source, persistent-ledger or UI consumer is admitted. The owning trial Run retains its frozen candidate, cumulative call/time limits, report-bound primary review and consumed holdout allowance.

Retirement, reproduction, replay or documentation cleanup does not reopen a
paused/rejected candidate, renew consumed generation calls or human-review
allowances, reset a budget, authorize private input, or approve a product/UI
transition. Current native model setup is separate; see [model tools](model-tools.md).
