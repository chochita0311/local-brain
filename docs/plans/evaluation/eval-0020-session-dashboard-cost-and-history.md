## Attempt 1 History Diagnosis (Superseded)

Read-only comparison of the registered personal source, normalized database,
existing LocalBrain migration backup and native Codex metadata establishes that
historical metadata can remain when its referenced JSONL is absent. The inspected
native conversation projection and cumulative counters do not provide the dated,
model-specific direct input/cache/output events required for reconstructed costs.
Current source/metric filtering is not sufficient to explain the missing source
bytes. The file-removal actor, time and cause are unestablished; this investigation
does not attribute removal to a feature change or provider migration.

The conclusion that recovery needed a separate backup was unsupported: this
inspection searched plain JSONL but omitted compressed originals. The owner
identified `.jsonl.zst`; attempt 2 found and decoded those originals. The backup
request and the original-history block are withdrawn. The earlier search did not
establish loss of source data. Attempt 2 below owns current
recovery evidence.

## Follow-up: Why Stored Usage Could Disappear

A temporary synthetic fixture verifies the destructive path separately from
the reverse-transition checks: import plain JSONL with the earlier revision,
replace it with its valid Zstd equivalent, then emulate the old plain-only
discovery. The scan reports zero imported/skipped/failed files while Session,
Activity Event and Usage Record counts each fall from one to zero; the compressed
original still exists. Stale-path reconciliation deletes the Session owner and
the Usage foreign key cascades that deletion. DB persistence did not provide an
independent historical-retention boundary.

This establishes a reproducible code defect, not the exact historical deletion
time, executing binary or introducing feature commit. The actual pre-recovery
gap and subsequent archive recovery remain observed evidence. Archive admission,
bidirectional owner retention and older-revision refusal address this compression
path. General successful-source missing-file reconciliation remains unchanged;
permanent Usage retention independent of absent originals was not implemented.
No live data was changed for this causal check, and the fixture was removed.

This is the pre-retention-extension finding. The later approved
[FEAT-0154](../feature/feat-0154-retained-session-history.md) changes that general
missing-input lifecycle; its [evaluation](eval-0154-retained-session-history.md)
owns current retention evidence. The old-discovery reproduction and its historical
attribution limits remain valid evidence of RUN-228's earlier boundary.
