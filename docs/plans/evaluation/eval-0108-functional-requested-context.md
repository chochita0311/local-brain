- Supplemented answers describe the total as a basic sample plus added material, most ambiguously in one answer. The exact frozen total is correct. Generated prose should distinguish the original count, added count, and final total.
- One valid next-message request assumes the omitted message is a user reaction. Position metadata establishes existence, not its role or whether it answers the question. Keep that uncertainty until retrieval.
- Request-feedback v2 asks for a fully visible initial goal, response, and reaction. The proposed trial has an observed correction and the assistant's admission, but the earlier specific request is absent. The core permits small trials from directly visible goals and burden. Their application to a retrospectively clarified goal is not settled by this case.

The primary accepts the proposal as a grounded, optional hypothesis for review, **not as proof that the strict initial-goal threshold or real usefulness has passed**. The current guide remains unchanged; this experiment does not silently relax its admission rule. Before another revision comparison, clarify the evidence needed for a future reversible trial separately from evidence needed to intervene in a currently unresolved problem. This is a bounded spec/playbook question, not grounds to force more recommendations or add broad persistent rules.
