## Acceptance And Limits

The approved behavior is delivered in the current web runtime. Retention covers
collected normalized history; it does not reconstruct uncollected raw content or
promise that an original will return. Known-empty/provider-excluded corrections,
Local Context lifecycle, immutable accounting and explicit deletion FKs remain
separately owned. Older executables are not retrofitted with this policy; result
revision admission still protects sources they recognize as newer. Human
acceptance remains separate from this same-author evaluation.
