## Bounded Correction

The initial shared renderer placed each newline inside an inline-block line span,
which displayed a two-line command as adjacent blocks. The privacy-safe witness
shape was two literal command lines with separate numeric spans. Moving the
separator outside each block restored separate rows in the rendered command
reader. The code pre owns horizontal overflow; the grid columns use minmax(0, 1fr).
No deterministic behavior test was added under the current no-test instruction;
the remaining regression evidence gap is explicit below.

The help checkbox now sits outside the hint disclosure and names both hints and
additional material. Opening extra source context can therefore mark help without
silently displaying a hint or implying an independent response. This interaction
has source inspection only.
