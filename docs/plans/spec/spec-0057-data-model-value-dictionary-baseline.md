## Implementation Contract

1. Add `src/localbrain/value-registry.json` as the one executable physical/logical/presentation authority.
2. Add `localbrain.value_registry` as the runtime loader and strict visible-label API. Runtime code never parses Markdown.
3. Cover every current physical `IN(...)` schema vocabulary, required stored application family, relevant boolean-like field, and eligible database-backed derived family.
4. Record excluded open vocabularies and structural constraints with a subject, owner, and reason.
5. Every included family declares:
   - physical field or projection;
   - complete values and enforcement class;
   - logical axis, default, and null/unknown/invalid/future policy;
   - producers, consumers, and consequence;
   - exactly one presentation mode;
   - exhaustive labels and help for `logical-label`, or no labels and no visible consumers for `internal-only`.
6. Generate one entrance and nine subject companions from the registry. Subject catalogs retain table/lifecycle ownership and link reciprocally.
7. Extend deterministic checks to compare schema vocabularies, selected Python constants, required inventories, generated bytes, links, and declared visible-consumer paths.
8. A consumer marked `registry-backed` must contain a family-specific `value_label` marker; current raw consumers remain explicitly `pending-normalization` for FEAT-0061.
9. Do not alter physical schema, existing rows, migrations, or visible product behavior in this Feature.

## State And Failure Contract

- Valid registry: all 54 current families load and generated docs are byte-current.
- Missing/incomplete logical mapping: registry validation fails.
- Schema or constant drift: the checker names the family and differing source.
- Missing consumer or raw fallback after `registry-backed`: the checker fails.
- Missing/stale generated document: check mode fails and instructs regeneration.
- Unknown visible runtime value: only an explicitly labeled fallback may render; otherwise the API rejects it.
- Internal family: visible-label lookup always fails closed.
