# Design System Change History

This file preserves dated changes to LocalBrain's design system. Entries describe
changes and decisions at the recorded time; later entries may supersede earlier
ones. The [Design Constitution](../../policies/design/design-constitution.md) owns
current visual and interaction rules. [Design Document Governance](../../policies/design/design-document-governance.md)
owns update and change-record duties.
