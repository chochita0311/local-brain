Local Contexts organizes registered document sources for browsing and search. Original files and Notes remain the source material.

## Connect documents

Open **Settings → Local Context**, choose **Add**, select a folder or file, and confirm registration. The chooser fills the path; it does not save it by itself. Apple Notes is a separate optional connection and requires the relevant macOS permission. See [Settings](/help/settings) for source management.

## Browse and read

1. Open [Local Contexts](/context) and choose a source under **Folders** or **Files**.
2. Select a document in its source tree to see the preview.
3. Open the full document reader when you need more room, then use its return link to continue browsing that source.

Source labels and paths help distinguish similarly named files. Within each Folder/File group, the explorer follows the source order saved in Settings. On wide screens, the tree and preview share the workspace; on narrow screens, use the same source and document links in their compact layout.

## Supported material and permissions

Folder sources collect supported Markdown documents. Individual text and Markdown files can also be connected. PDF import requires text available through Spotlight. Image-only scans are not indexed as text.

Apple Notes access is optional. If macOS denies permission, that connection cannot be read; other sources remain usable. A missing, unreadable, or unsupported file is a source/readability issue rather than an empty document you should assume is indexed successfully.

Reading does not edit the original. Unsupported attachments or embedded images may remain readable markers instead of rendered media.

## Refresh or disconnect

Local Context has its own automatic collection interval, normally **30 minutes after the previous collection finishes**. Reopen or reload the view after collection to see new material; the reading pane is not force-refreshed. Change the schedule in [Settings](/help/settings).

Confirm the source is registered, its path is current, and the application has read access. A selected path is not registered until it is saved. Check the selected Folder or File source when locating a document. For Apple Notes, check its access permission. Unsupported or unreadable material is not guaranteed to appear after another scan.

**Unregister** requires confirmation. It stops collection and removes the source from search and browsing, clearing its search entries. LocalBrain keeps its saved source details and imported documents so you can register it again. Original files and Apple Notes stay unchanged.

Use [Search](/help/search) to find material across Sessions and readable registered documents. [Settings](/help/settings) explains source registration and synchronization.
