연결한 AI 소스에 기록된 사용량을 기간별로 비교하고 예상 비용을 확인합니다.

## 기간 선택

1. [Sessions Dashboard](/sessions-dashboard)를 엽니다.
2. **전체** 또는 소스 프로필을 선택하고 기간·시작일·종료일을 정합니다.
3. 요약을 읽고 기록의 지표를 토큰·비용으로 바꿉니다.
4. **소스별·모델별·프로젝트별** 구성을 확인합니다.

선택한 시간대가 날짜 경계와 일·주·월 묶음을 정합니다. 시간대를 바꾸면 표시 기간이 달라질 수 있지만 원본 기록은 바뀌지 않습니다. [설정](/help/settings)에서 변경하세요.

## 비용과 자료 범위

| 표시 | 의미 |
| --- | --- |
| 예상 비용 | 로컬 사용량과 확인 가능한 가격으로 계산한 추정치. 제공 업체의 청구서나 청구 금액 보장은 아닙니다. |
| 일부만 계산 | 선택한 사용량 중 일부에만 가격을 적용할 수 있습니다. |
| 비용 확인 불가 | 0원이 아닙니다. 수치 옆 자료 범위 안내를 함께 읽으세요. |
| 토큰 기록 없음 | 작업이 없었다는 뜻은 아닙니다. 다른 기간·소스에 기록이 있더라도 현재 필터에는 없을 수 있습니다. |

## 프로젝트별 집계

**프로젝트별**에는 일반 작업 세션과 그 작업 하위 세션을 포함합니다.
사용량에 기록된 Git 루트 또는 실행 폴더를 따르며 해당하는 경우 Home도 포함합니다.
귀속 정보가 없는 일반 작업은 **프로젝트 미지정**입니다.

분석·유지관리 사용량은 프로젝트 행·합계·비율에서 제외합니다. 해당 사용량 중 집계 가능한 부분은 전체 합계·기간 기록·소스별·모델별 구성에 남으므로 프로젝트 합계와 다를 수 있습니다.

프로젝트 귀속은 사용량 기록에 보존됩니다. Sessions의 작업 경로 묶음이나 Chart의 실행 폴더와 반드시 같지는 않습니다. 경로 표시가 짧아져도 과거 사용량을 다른 프로젝트로 옮기지 않습니다.

## 기록이 부족할 때

먼저 소스·날짜·시간대를 확인하세요. [설정](/help/settings)에서 등록·읽기 권한을 확인하고 필요하면 세션을 동기화한 뒤 대시보드를 다시 엽니다.
사용량이 있어도 가격·사용량 근거가 부족한 지표는 다시 수집한다고 반드시 복구되지는 않습니다.

- **Codex 원본:** 등록한 프로필의 `.jsonl`과 `.jsonl.zst`를 직접 읽습니다. 압축을 풀 필요가 없으며 원본이 없다고 판단하기 전에 두 형식을 모두 확인하세요.
- **두 형식 모두 없음:** 이미 수집한 사용량은 DB에 남습니다. 한 번도 수집하지 않은 사용량은 대화 목록·누적 토큰 카운터로 복원할 수 없고 원본이나 백업이 필요합니다.
- **동기화 이후:** 대시보드 사용량과 정규화된 Codex 대화는 로컬 DB에서 읽습니다. 압축은 수집 중 해독하며 추출한 대화 파일을 만들지 않습니다.
- **같은 폴더에 `name.jsonl`과 `name.jsonl.zst`가 모두 파일로 존재:** `.jsonl`만 수집합니다. 내용을 합치거나 최신 여부를 비교하지 않습니다. 형식을 바꿔도 같은 세션·기존 핀·고정된 사용량 정보는 유지됩니다. 이 규칙은 등록 소스별로 적용하며 개인·회사 프로필을 합치지 않습니다.

대화를 읽으려면 [세션](/help/sessions), 등록·동기화 방법은 [설정](/help/settings)을 참고하세요.
