톱니바퀴 **설정** 또는 `⌘,`로 엽니다. 앱 옵션, 연결 소스, 검색, 동기화와 저장공간을 관리합니다.

설정을 읽는 동안 저장된 선택이 먼저 표시되며, 확인 결과가 필요한 조작은 기다려야 합니다.
읽기 오류는 다른 항목으로 이동해도 유지됩니다. 원인을 해결한 뒤 **다시 불러오기**를 누르세요.
프로필 목록을 읽지 못했다고 등록이 삭제된 것은 아닙니다.

첫 실행 안내가 열리지 않을 때 준비 화면의 **다시 불러오기**는 현재 안내 페이지를 다시 엽니다.
소스 등록이나 안내 완료를 대신 수행하지 않습니다.

## 일반

**시작 화면:** Sessions Dashboard, Sessions, Local Context 중 선택합니다. 기본값은 **Sessions**이며 다음 앱 실행부터 적용됩니다.

**시간대:** UTC 또는 Asia/Seoul을 선택합니다. 이전에 저장한 다른 유효한 시간대는 바꾸기 전까지 유지됩니다.
다음 화면 이동·새로고침부터 세션·대화·차트의 시각, 대시보드 날짜 범위와 일·주·월별 묶음에 적용됩니다.
자정 근처 기록은 표시 날짜가 달라질 수 있습니다. 예를 들어 **서울 19일 00:30은 UTC 18일 15:30**입니다.
원본 타임스탬프, 시스템 시계, 저장한 동기화 간격은 바뀌지 않으며 세션·문서 타이머는 각자의 경과 시간을 따릅니다.

저장한 옵션은 앱을 다시 열어도 유지됩니다. 아직 설정하지 않은 항목에만 기본값을 사용합니다.

## 세션 소스

1. **프로필 추가**에서 **도구**를 Codex 또는 Claude Code로 선택합니다.
2. **프로필 이름**과 에이전트 **Home**을 입력합니다. 기본 기록 위치는 Codex Home 아래 `sessions`, Claude Code Home 아래 `projects`입니다.
3. 다른 위치라면 **별도 세션 폴더**를 펼쳐 실제 기록 폴더를 지정합니다. 이 경우 Home은 선택 사항입니다. 별도 폴더는 Home을 바꿔도 고정되며 **기본 폴더 사용**으로 원래 관계를 복원합니다.
4. **추가** 또는 **저장**을 누릅니다. 폴더 선택·발견된 프로필 제안은 편집기에 채우기만 하며 자체적으로 등록·수집하지 않습니다.

- 등록한 **기록 폴더만** 수집하며 전체 Home을 읽지 않습니다.
- 프로필을 여러 개 등록할 수 있지만 같은 폴더·서로 겹치는 기록 폴더는 거부합니다.
- 이름을 바꿔도 소스 식별자는 유지됩니다. 기존 기록 위치를 옮길 때는 같은 프로필과 일치하는 기록인지 확인해야 합니다.
- 취소하거나 다른 설정 항목으로 이동하면 미저장 입력을 버립니다. 첫 실행 안내의 **이전**은 입력을 보존합니다.
- 행의 손잡이를 드래그하거나 화살표 키로 순서를 저장합니다.
- **등록 해제**는 확인 후 수집과 일반 검색에서 제외합니다. 가져온 기록과 원본은 유지되며 다시 등록할 수 있습니다.

## Local Context

**추가**에서 폴더·파일을 고른 뒤 등록을 확인합니다. Apple Notes는 선택 사항이며 macOS 권한을 요청할 수 있습니다.
**Apple Notes 연결**은 **추가** 화면 아래에 있습니다. 연결을 마치면 기본 소스 목록에 **Apple Notes · Notes.app**이 표시되고, 추가 화면의 Notes 연결 영역은 숨겨집니다. 등록을 해제하면 연결 영역이 다시 나타납니다.
폴더는 지원하는 Markdown 문서를 수집합니다. 개별 텍스트·Markdown·지원 PDF도 연결할 수 있습니다.
형식·읽기 제한은 [로컬 문서](/help/local-contexts)를 참고하세요.

행 손잡이로 순서를 바꿉니다. 취소·항목 이동은 편집 초안을 버리고, 첫 실행의 **이전**은 보존합니다.
**등록 해제**를 확인하면 수집을 멈추고 검색·탐색에서 제외하며 검색 항목을 지웁니다.
소스 설정과 가져온 문서는 보관하여 재등록할 수 있습니다. 원본 파일과 Apple Notes는 바뀌지 않습니다.

## 검색 모델

키워드 검색에는 모델이 필요하지 않습니다. 임베딩 모델 다운로드가 끝나면 AI 검색 준비가 자동 시작됩니다.
설치·다운로드 조건·준비 상태는 [검색](/help/search)에서 확인하세요.

모델·검색 상태를 확인해야 하는 조작은 확인 전까지 사용할 수 없습니다.
검색 상태 확인에 실패하면 **다시 확인**을 사용하세요. 설정 전체를 불러오지 못했다면 **다시 불러오기**를 사용하거나 다음 상태 확인에서 복구된 뒤 실행하세요.

**최소 관련도**는 0–1 사이 숫자로 조절하며, 입력을 마치면 자동 저장합니다. **기본값 복원**은 0.45로 되돌립니다.
저장 실패 시 입력 옆의 안내에서 **다시 저장**을 사용하세요. 다른 창에서 설정이 바뀌면 현재 설정을 다시 확인한 뒤 재시도합니다. 저장한 값은 다음 검색부터 적용됩니다. 관련도 기준의 의미는 [검색 안내](/help/search)를 참고하세요.

### 모델 보관과 다운로드

설치 상태 아래 **저장 폴더**에서 경로를 입력하거나 **찾아보기**로 고릅니다.
**폴더 확인** 후 모델이 있으면 **이 폴더 사용**으로 연결하고, 없으면 **이 폴더에 다운로드**를 직접 실행합니다.
검증이나 다운로드를 마치기 전까지 기존 위치를 유지하며, 기존 모델 파일은 옮기거나 지우지 않습니다.
이 설정은 검색 모델 파일에만 적용됩니다. 앱 데이터·등록 정보·검색 색인의 위치는 바뀌지 않습니다.

| 저장 위치 | 보관 내용 |
| --- | --- |
| 모델 저장 폴더 | 공개 모델 원본. 기본은 Hugging Face 캐시(보통 `~/.cache/huggingface/hub`)이며, 검색 모델에서 선택한 폴더가 있으면 그 위치를 사용합니다. |
| LocalBrain 데이터 | 앱의 모델 등록 메타데이터 |
| LocalBrain 캐시 | 추론·커널 캐시 |

완전한 모델 캐시를 연결하면 다시 다운로드하지 않습니다. 상태 조회는 로컬 파일의 존재를 확인하며 실제 사용 전 작업자가 무결성을 검사합니다.
앱 캐시 정리는 공유 모델 원본을 보존합니다.
선택한 폴더가 기본 공유 캐시와 별도라면 저장공간에 두 위치를 함께 표시합니다. 중단 후 같은 폴더를 다시 선택하면 받은 파일 조각을 재사용할 수 있습니다.

다운로드 재개·인터넷 연결·개인정보 처리는 [검색의 다운로드 안내](/help/search)를 참고하세요.

## 동기화

세션과 Local Context는 서로 다른 일정을 사용합니다.

| 항목 | 기본 간격 | 선택 가능 값 |
| --- | --- | --- |
| 세션 | 이전 수집 **완료 후 10분** | 10·20·30·60분 또는 끄기 |
| Local Context | 이전 수집 **완료 후 30분** | 10·20·30·60분 또는 끄기 |

선택한 일정만 즉시 저장합니다. **끄기**는 기존 간격과 가져온 자료를 보존하며, 분 단위를 고르면 켜집니다.
이전에 저장한 유효한 사용자 지정 간격은 변경 전까지 표시합니다. 변경은 다음 일정 판단부터 적용하며 진행 중인 수집을 중단하지 않습니다.

등록된 소스만 앱 실행 중에 읽습니다. **완전히 종료**하면 중단되며 창만 닫으면 계속됩니다.
Sessions의 **동기화**는 수동 요청입니다. 백그라운드 수집은 현재 화면을 유지하므로 새 자료는 다시 열거나 새로고침해 확인하세요.
AI 검색이 켜져 있으면 수집 자료 변경에 맞춰 검색 인덱스도 갱신합니다.

## 저장공간

실제 설정된 위치와 일반 파일의 논리적 크기를 **GiB**(1024³바이트)로 표시합니다. 실제 디스크 점유량과 다를 수 있습니다.
아직 없는 위치는 빈 상태, 읽기 불가·일부 집계는 각각 표시합니다. 여유 공간은 각 위치가 있는 볼륨 기준이며 같은 볼륨은 한 번 표시합니다.
공유 공개 모델 캐시 크기에는 다른 앱·모델의 파일도 포함됩니다.
앱 실행 파일, 소스 checkout, Python·Node·Rust 도구와 빌드 캐시는 이 합계에 포함되지 않습니다. 소스 빌드에는 별도 공간이 필요합니다.

| 항목 | 보관 내용 |
| --- | --- |
| 데이터·설정 | 가져온 기록과 앱 설정 |
| 앱 캐시 | 다시 만들 수 있는 생성 데이터 |
| 공유 공개 모델 캐시 | 다운로드한 가중치. 다른 모델·도구가 쓰는 파일도 포함 |

세션·문서 원본은 등록한 위치에 그대로 있습니다.

### 백업

**설정 → 저장공간 → 백업 파일 저장**으로 ZIP을 만듭니다.

- **포함:** DB 스냅샷, 일반·소스·검색 설정, 모델 등록 메타데이터.
- **제외:** 세션·문서 원본, 모델 가중치, 캐시, 로그, 외부 인증 정보.

백업에는 저장한 개인 자료가 담깁니다. 앱 설치 파일과 별도로 보관하세요.

### 복원

1. **같은 LocalBrain 설치·같은 컴퓨터**에서 만들었고 현재 앱과 **DB 스키마가 같은** 백업을 사용합니다. 스키마가 다르면 백업을 만든 앱 버전으로 복원하세요.
2. **백업에서 복원**을 펼쳐 ZIP을 선택하고 데이터·설정 교체를 명시적으로 확인합니다.
3. **복원 예약** 후 실행 중인 LocalBrain을 모두 완전히 종료하고 다시 실행합니다. 교체는 시작 시 적용됩니다.

데이터 폴더의 `recovery`에 복원 전 사본을 남기며 실패하면 이전 상태로 되돌립니다.
복원해도 백업에 없는 원본은 돌아오지 않고 모델 가중치를 다운로드하지도 않습니다.

### 캐시 정리

**캐시 정리**는 LocalBrain이 만든 비활성 검색 캐시를 지웁니다.
원본 자료와 다운로드한 모델은 보존합니다. 검색 캐시는 AI 검색을 켜면 다시 만들 수 있습니다.
