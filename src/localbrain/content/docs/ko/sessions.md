가져온 Codex·Claude Code 대화를 다시 읽습니다. **List**는 대화 탐색, **Chart**는 기록된 시점별 활동 확인에 사용합니다.

## 대화 찾기

1. [Sessions](/sessions)에서 **전체** 또는 소스 프로필을 고르고 필요하면 작업 경로를 좁힙니다.
2. **List**에서 대화를 찾습니다. **Projects**는 세션에서 확인한 작업 경로별 묶음입니다.
3. 세션을 열어 대화·원본 세션 ID·최근 활동·경로·기록된 브랜치를 확인합니다.
4. **하위 세션**으로 자식 대화를 읽고 부모·목록 복귀 링크로 돌아갑니다.

대화 화면은 메시지를 보여줍니다. 원본 이벤트 수에는 화면에서 숨기는 도구 활동도 포함되어 메시지 수와 다를 수 있습니다. 현재 작업 폴더가 없다는 이유만으로 가져온 대화가 지워지지는 않습니다.

## 원본이 사라진 세션

수집한 대화는 원본 파일이 없어도 읽기·핀 추가/해제·기록된 사용량 조회를 계속할 수 있습니다.
원본 상태는 작업 폴더 상태와 별개입니다.

| 표시 | 의미 |
| --- | --- |
| 원본 있음 | 원본 존재를 확인했습니다. 별도의 수집 오류는 있을 수 있습니다. |
| 원본 없음 | 검사에서 원본이 없음을 확인했습니다. |
| 원본 확인 불가 | 존재·부재를 판단하지 못했습니다. 없음으로 간주하지 않습니다. |

상세에는 마지막 원본 확인 시각과 확인 가능한 사유를 표시합니다.
동기화는 사용 가능한 입력에 대해 계속됩니다. 원본이 없으면 강제 동기화·업그레이드 때도 수집 데이터와 이전 처리 버전을 유지합니다.
원본이 돌아오면 같은 세션을 갱신하며 핀과 고정된 사용량 귀속을 보존합니다.
한 번도 수집하지 않은 정보는 원본 없이 재구성할 수 없지만, DB에 있는 자료의 읽기·계산은 계속됩니다.

세션 ID는 짧게 표시합니다. 전체 원본 식별자는 복사 버튼을 사용하세요.
경로는 Home 자체를 `~`, 그 아래를 `~/…`, 외부를 전체 경로로 표시합니다.
예: `~/Projects/app`, `~/Project1`, `~/Project2`. 저장 위치나 과거 프로젝트 귀속은 바뀌지 않습니다.

## 관련 자료

기본 세션의 **관련 자료**에는 그 대화에서 직접 언급한 Markdown·URL과 기록된 자료 조회 결과가 표시됩니다.
Markdown 경로가 조건에 맞는 인덱싱된 Local Context 문서 하나로 해석될 때 해당 문서를 엽니다.
작업 조직의 소속이나 작업 폴더가 같다는 이유만으로 다른 자료를 추가하지 않습니다.
직접 참조가 없으면 빈 상태를 표시하며, 하위 세션에는 이 영역이 없습니다.

## 핀

List 또는 상세의 핀 버튼으로 **기본 작업 세션**을 고정합니다.
해제는 바로가기만 없애며 원본 대화는 삭제하지 않습니다. 하위 세션은 별도로 고정하지 않고 부모를 통해 엽니다.

## Chart

**List → Chart**로 전환해도 소스·작업 경로 범위를 유지합니다. 기록된 시각·실행 폴더·브랜치를 사용합니다.

| 조작 | 동작 |
| --- | --- |
| 프로젝트 선택 | 폴더 표시·숨김. 현재 범위별 선택을 저장하며 세션을 삭제하지 않습니다. |
| − / +, 전체 보기 | 배율 변경, 전체 차트 맞춤 |
| 노드 위 포인터·키보드 초점 | 미리보기. 노드를 선택하면 열린 상태를 유지합니다. |
| 미리보기의 세션 상세·활동 시각 | 대화 또는 기록된 이벤트 확인 |
| 선택으로 이동 | 선택한 세션을 읽기 좋은 배율로 다시 표시 |
| Shift + 휠 | 가로 이동 |
| ⌘/Ctrl + Shift + 휠 | 시간 간격 조절 |

차트는 관찰된 활동을 보여줍니다. Git 계보·추론한 작업 계획을 나타내지 않으며 브랜치가 같다고 세션 간 인과관계가 입증되지는 않습니다.
불러오지 못하면 **List로 보기**를 사용하세요.

## 최신 기록 확인

**동기화**는 등록한 세션 소스 수집을 요청합니다. 자동 수집 주기는 [설정](/help/settings)에서 관리합니다.
백그라운드 수집은 읽는 화면을 방해하지 않으므로 새 기록은 다시 열거나 새로고침해 확인하세요.

수집 전 등록 여부·기록 폴더·읽기 권한을 확인합니다. 폴더 선택·발견만으로 등록되지는 않습니다.
기록을 옮겼다면 겹치는 프로필을 새로 추가하지 말고 같은 프로필을 다시 연결하세요. 찾는 세션이 없으면 소스·작업 경로 필터도 확인합니다.

기억나는 표현은 [검색](/help/search), 사용량 합계는 [세션 대시보드](/help/sessions-dashboard)에서 확인하세요.
