등록한 문서를 탐색하고 검색합니다. 원본 파일과 Apple Notes는 그대로 보존합니다.

## 문서 연결

**설정 → Local Context → 추가**에서 폴더·파일을 고른 뒤 등록을 확인합니다.
선택 창은 경로만 채우며 저장하지 않습니다. Apple Notes는 별도의 선택형 연결이며 macOS 권한이 필요합니다.
소스 관리는 [설정](/help/settings)을 참고하세요.

## 찾아 읽기

1. [Local Contexts](/context)의 **Folders** 또는 **Files**에서 소스를 고릅니다.
2. 소스 트리에서 문서를 골라 미리 봅니다.
3. 넓게 읽으려면 전체 문서를 열고, 복귀 링크로 같은 소스 탐색을 이어갑니다.

소스 이름과 경로로 같은 이름의 파일을 구분하세요. 각 Folder/File 그룹은 설정에 저장한 순서를 따릅니다.
넓은 화면에서는 트리·미리보기를 나란히 사용하며 좁은 화면에서는 같은 소스·문서 링크를 작은 배치로 사용합니다.

## 지원 형식과 권한

| 자료 | 지원 범위 |
| --- | --- |
| 폴더 | 지원하는 Markdown 문서 수집 |
| 개별 파일 | 텍스트·Markdown·지원 PDF 연결 |
| PDF | Spotlight로 읽을 수 있는 텍스트가 필요. 이미지 스캔만 있는 PDF는 텍스트로 인덱싱하지 않습니다. |
| Apple Notes | 선택형. macOS에서 거부하면 이 연결만 읽지 못하며 다른 소스는 계속 사용할 수 있습니다. |

없거나 읽지 못하거나 지원하지 않는 파일은 소스·읽기 문제입니다. 성공적으로 인덱싱한 빈 문서로 간주하지 마세요.
읽기는 원본을 수정하지 않습니다. 지원하지 않는 첨부·이미지는 미디어 대신 안내 표식으로 남을 수 있습니다.

## 새로 수집하거나 연결 해제

자동 수집은 세션과 별개이며 기본값은 **이전 문서 수집 완료 후 30분**입니다. [설정](/help/settings)에서 바꿉니다.
수집 후 다시 열거나 새로고침해 새 자료를 확인하세요. 읽는 창은 강제로 갱신하지 않습니다.

자료가 없으면 등록 상태·현재 경로·읽기 권한·선택한 Folder/File 소스를 확인하세요.
선택한 경로는 저장 전에는 등록되지 않습니다. Apple Notes는 접근 권한도 확인합니다.
지원하지 않거나 읽지 못하는 자료는 재수집해도 나타난다고 보장할 수 없습니다.

**등록 해제**를 확인하면 수집을 멈추고 검색·탐색에서 제외하며 검색 항목을 지웁니다.
다시 등록할 수 있도록 소스 설정과 가져온 문서는 남깁니다. 원본 파일과 Apple Notes는 변경하지 않습니다.

[검색](/help/search)으로 세션과 읽을 수 있는 등록 문서를 함께 찾아보세요. 등록·동기화는 [설정](/help/settings)에서 관리합니다.
