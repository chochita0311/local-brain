LocalBrain에서 AI 코딩 대화와 프로젝트 문서를 모아 읽고, 이전 작업을 다시 찾을 수 있습니다.

## 설치와 실행

첫 체험은 **Git 저장소 받기 → 코딩 에이전트에게 빌드·설치 요청 → 앱 실행** 순서입니다.
[README 설치 안내](https://github.com/chochita0311/local-brain#install-from-source-with-an-agent)를 에이전트에게 전달하세요.
완성된 앱을 받았다면 해당 앱을 설치해 실행하면 됩니다. 빌드 도구 안내는 저장소에 있으며,
설치 후 일상적인 사용에는 소스 checkout이나 직접 실행하는 개발 서버가 필요하지 않습니다.

## 처음 연결하기

첫 실행 안내는 **환영 → 세션 → 문서 → 검색** 순서입니다.

1. **세션:** Codex 또는 Claude Code 프로필을 연결합니다. Home과 세션 폴더는 [설정](/help/settings)에서 확인하세요.
2. **문서:** 폴더·개별 파일 또는 선택형 Apple Notes를 연결합니다. [로컬 문서](/help/local-contexts)에서 읽을 수 있습니다.
3. **검색:** 키워드로 시작하세요. [AI 검색 모델](/help/search)은 선택 사항입니다.
4. 마지막 **시작** 또는 **건너뛰기**로 마칩니다. **나중에 설정**을 선택한 뒤 소스를 연결해도 됩니다.

| 조작 | 세션·문서 단계의 입력 처리 |
| --- | --- |
| 다음 | 입력 중인 소스를 저장합니다. |
| 이전 | 입력을 유지합니다. |
| 건너뛰기 | 현재 초안을 등록하지 않습니다. |
| 완료 전에 앱 종료 | 다음 실행에 안내가 다시 열립니다. 이미 저장한 소스는 유지됩니다. |

설정은 톱니바퀴 **설정** 또는 `⌘,`로 엽니다.

## 첫 자료 찾기

세션 소스를 등록한 뒤 [Sessions](/sessions)에서 **동기화**하면 바로 수집합니다.
앱이 실행 중이면 세션과 문서도 각자의 주기로 자동 수집합니다. 주기는 [설정](/help/settings)에서 바꿉니다.

세션을 열어 대화를 읽거나 [Local Contexts](/context)에서 문서를 선택하세요.
공통 검색창에 기억나는 표현을 입력해 찾을 수도 있습니다. 폴더를 발견하거나 선택한 것만으로는 연결되지 않으며, **명시적으로 등록**해야 합니다.

## 화면 사이 이동

사이드바는 **LocalBrain 로고 오른쪽 버튼**으로 접고 펼칩니다. 접어도 메뉴 아이콘은 남습니다. Mac 앱의 뒤로·앞으로·검색은 **창 제목 표시줄**, 브라우저에서는 **페이지 상단 툴바**에 있습니다.

| 기능 | Mac | 그 외 데스크톱 브라우저 |
| --- | --- | --- |
| 뒤로 / 앞으로 | `⌘[` / `⌘]` | `Alt+←` / `Alt+→` |
| 사이드바 접기·펼치기 | `⌘⇧S` | `Ctrl+Shift+S` |
| 검색창으로 이동 | `⌘K` | `Ctrl+K` |

사용 가능한 탐색 아이콘에 마우스를 올리거나 키보드로 포커스를 옮기면 이름과 단축키가 표시됩니다. 검색창·Search에는 별도 호버 안내가 없고, 비활성화된 뒤로·앞으로에도 이름·단축키 안내가 표시되며, 금지 커서로 누를 수 없는 상태를 알립니다. 각 키는 개별 키 모양으로 구분하며, Escape로 안내를 닫습니다. 사이드바 상태는 현재 창에서 화면을 이동해도 유지됩니다. 뒤로 간 뒤 **→**로 돌아갈 수 있고, 새 화면을 방문하면 앞으로 기록은 지워집니다.

- 상단 **←** 버튼은 세션·상세·문서·검색·설명서를 방문한 순서로 돌아갑니다. URL 필터·선택·읽던 위치를 유지합니다.
- 현재 앱 창의 **최근 50지점(현재 화면 포함)**을 기억해 최대 49단계 돌아갑니다. 첫 지점에서는 비활성화됩니다.
- 새로고침·백그라운드 갱신은 이동으로 쌓지 않습니다. 앱을 완전히 종료하면 다음 실행에 새 이력을 시작합니다.

## 종료와 업데이트

- **창 닫기:** 앱은 계속 실행됩니다. 앱 아이콘을 열면 창이 다시 나타납니다.
- **완전히 종료:** **Quit** 또는 **⌘Q**를 사용합니다. 동기화와 다운로드가 중단됩니다.
- **업데이트:** 완전히 종료한 뒤 새 앱으로 교체하고 다시 실행합니다. 앱 교체·삭제만으로 저장한 데이터와 설정이 지워지지는 않습니다. 백업·복원은 [설정](/help/settings)을 참고하세요.
- **소스로 설치한 앱:** 저장소를 pull한 뒤 에이전트에게 데이터·설정을 보존하면서 재빌드·교체하도록 요청하세요. **pull만으로 설치된 앱이 갱신되지는 않습니다.**
