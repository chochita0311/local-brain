원본 대화와 등록한 문서를 찾습니다. 로컬 AI 모델이 설치되고 AI 검색이 켜져 있으면 자동으로 AI 검색을 사용합니다. 모델이 없거나 AI 검색을 꺼두면 키워드로 찾습니다.

## 검색하기

1. 공통 검색창에 기억나는 단어·표현을 입력합니다.
2. AI 검색이 켜져 있으면 찾고 싶은 내용을 설명합니다. 키워드 검색을 사용하는 상태에서는 여러 검색어가 **모두 함께 일치**해야 합니다. 특징적인 단어를 적게 사용해 보세요. 검색 방식을 따로 선택할 필요는 없습니다.
3. 결과 또는 근거 링크로 원본 대화·문서를 읽고, 복귀 링크나 브라우저 뒤로 가기로 결과에 돌아옵니다.

검색 후에는 결과 개수와 목록을 바로 표시합니다. 다시 검색할 때는 상단 검색창을 사용하세요. 준비 중·일부 갱신·실패처럼 검색에 영향을 주는 상태만 함께 표시하며, 준비가 끝나면 **같은 검색 다시 실행**으로 결과를 다시 불러올 수 있습니다.

| 포함 | 제외 |
| --- | --- |
| 등록 소스의 검색 가능한 기본 작업 세션, 켜져 있고 읽을 수 있는 Local Context | 하위 세션, 미등록 소스, 읽지 못하는 문서, 지원 범위 밖 자료, 앱 관리 데이터·캐시 |

하위 세션은 [세션](/help/sessions)의 부모를 통해 엽니다.

## 선택형 AI 검색 준비

1. **설정 → 검색 모델**을 엽니다.
2. **모델 다운로드**를 누릅니다. 현재 모델은 **Qwen3-Embedding-0.6B**, 약 **1.21 GB**입니다. 인덱스·임시 작업에는 추가 저장공간과 메모리가 필요합니다.
3. 다운로드가 끝나면 검색 준비가 자동 시작됩니다. 준비 완료를 기다립니다.
4. 검색창에서 찾고 싶은 자료를 설명합니다. 설치하고 켠 AI 검색을 자동으로 사용합니다.

설치된 모델로 AI 검색을 켤 때는 **AI 검색 켜기**를, 켜진 상태에서 수집 자료를 다시 반영하거나 준비를 재시도할 때는 **색인 업데이트**를 사용합니다.

### 다운로드 조건과 복구

다운로드에는 인터넷과 시스템이 신뢰하는 인증서가 필요합니다.
검색어·문서는 LocalBrain에서 처리하며 원격 AI 서비스로 보내지 않습니다. 다운로드한 모델 가중치는 앱 백업과 별도로 저장합니다.

다운로드 실패 시 연결·여유 공간·네트워크 인증서 설정을 확인하고 재시도하세요.
**인증서 검증은 켜 둡니다.** 모델·인덱스·임시 작업에는 다운로드 크기보다 많은 공간이 필요합니다.

진행 중인 다운로드·준비는 취소할 수 있습니다. 중단한 다운로드는 받은 파일 조각을 재사용해 재개할 수 있습니다.
모델 원본의 재사용과 저장 위치, 캐시 정리 시 보존 범위는 [설정의 모델 보관 안내](/help/settings)를 참고하세요.
AI 검색을 꺼도 키워드 검색은 유지됩니다.

### 자동 업데이트

AI 검색이 켜져 있으면 앱 실행 중 대기 상태에서 5초 간격으로 변경을 확인하고, 수집된 자료가 바뀌면 자동으로 업데이트합니다. 원본 수집 주기는 동기화 설정을 따르며, 반영 시점은 수집 일정과 색인 작업 시간에 따라 달라집니다.
5초는 변경 확인 간격이며, 모든 자료의 업데이트 완료 주기가 아닙니다. 동기화 주기와 수집 조건은 [설정의 동기화 안내](/help/settings)를 참고하세요.

## 검색 결과의 관련도

**설정 → 검색 모델 → 최소 관련도**에서 의미검색의 기준을 조절합니다. 범위는 **0–1**, 기본값은 **0.45**입니다.
낮추면 더 폭넓게, 높이면 더 엄격하게 찾습니다. 정확도나 정답 확률을 뜻하는 숫자는 아닙니다.
값을 바꾸고 입력을 마치면 자동 저장하며 다음 검색부터 적용합니다. 색인을 다시 만들 필요는 없습니다. **기본값 복원**으로 0.45로 돌아갑니다.
코드명·파일명처럼 정확히 일치하는 항목은 기존 일치 보완 규칙을 따릅니다.

## 상태에 따른 다음 행동

| 상태 | 다음 행동 |
| --- | --- |
| 꺼짐·모델 없음 | 키워드 검색 사용. 모델이 없으면 다운로드하고, 설치되어 있으면 준비해 AI 검색을 켭니다. |
| 준비 중 | 안내를 확인하고 기다리거나 취소합니다. |
| 일부 준비·실패 | 안내를 확인한 뒤 제공된 준비·재시도를 사용합니다. |
| 결과 없음 | 현재 조건에 맞는 자료가 없습니다. 설명·제약을 조정하세요. 준비되지 않은 상태와는 다르며 준비 성공이 일치를 보장하지 않습니다. |

AI 검색 실패·빈 결과에서 키워드로 자동 전환하지 않습니다. 검색 모델 설정을 바꾸면 현재 입력을 유지한 채 사용할 검색 방식을 반영합니다. 설정 중이거나 검색어를 입력하는 동안에는 화면을 바꾸지 않습니다.
검색어 없이 검색 화면을 열면 준비 수량과 검색 범위 상세를 확인할 수 있습니다.
결과 발췌문은 원본 근거로 연결되며 원본을 대체하는 생성 답변이 아닙니다.

등록은 [설정](/help/settings), 문서 연결·읽기는 [로컬 문서](/help/local-contexts)를 참고하세요.
