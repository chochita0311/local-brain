# Context recovery · v1 (`context_recovery`)

- **Trigger:** Background, decisions, constraints, or links are reconstructed after interruptions or across Sessions.
- **Exclude:** Intentional restatement for a new audience, changed scope, or a stale earlier source.
- **Evidence questions:** Are the earlier source and later restatement both inspectable? Which facts remained current? Was an existing handoff available?
- **Benign alternative:** Restating context can be useful for teaching or checking shared understanding.
- **Intervention:** Try a short source-linked handoff with current goal, established facts, unresolved points, and next step in an existing knowledge location.
- **Output sketch:** Identify one repeated reorientation and propose a compact handoff, without copying full conversations.
- **Follow-up:** On the next resume, ask whether the person could start from the current decision.
- **Current-source limit:** Sampled excerpts may miss the original decision or interruption; request bounded source context before calling it repeated loss.
