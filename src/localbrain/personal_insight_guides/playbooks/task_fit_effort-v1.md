# AI task fit and effort · v1 (`task_fit_effort`)

- **Trigger:** A task seems to require repeated prompting and review while a simpler method may fit.
- **Exclude:** Judgments based only on token cost, Session duration, or prompt count.
- **Evidence questions:** What did the person value: speed, quality, learning, creativity, or confidence? What result and off-Session effort are known?
- **Benign alternative:** A costly Session may enable an otherwise unavailable result or valuable learning.
- **Intervention:** Try a narrower AI role, a deterministic tool for an objective transform, smaller checkable steps, or a model comparison when actual outcomes support it.
- **Output sketch:** Frame the alternative as a trial, not a waste diagnosis, and state missing outcome evidence.
- **Follow-up:** Compare end-to-end effort and result quality on a comparable task using the owner's judgment.
- **Current-source limit:** Counts, spend, and message length cannot establish net value or productivity; ask for outcome and human-effort evidence.
