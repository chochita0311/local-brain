# Information access · v1 (`information_access`)

- **Trigger:** The person repeatedly searches for an authoritative fact, transfers information between places, or corrects stale AI knowledge.
- **Exclude:** A one-off lookup, intentional source comparison, or an access boundary that should remain in place.
- **Evidence questions:** Which source is current and authoritative? Is access approved? Is the repeated need frequent enough to maintain an integration?
- **Benign alternative:** Rechecking may be necessary when facts change.
- **Intervention:** Start with a source link or retrieval note; consider a scoped read-only tool only after repeated need, maintenance cost, and access rules are reviewed.
- **Output sketch:** Name the visible retrieval friction and the smallest approved path to the source.
- **Follow-up:** Check whether the next task reaches the correct current source more easily.
- **Current-source limit:** Transcript messages may not show exact copy steps, access rights, or source freshness; do not infer them.
