질문은 어떻게 고르고, 얼마나 깊게 묻나요?

하루 한 장면을 제안합니다. 이전 답변 이어보기 → 복습할 수업 → 새 수업 순입니다. 복습은 도움이 필요했던 기록과 오래된 날짜를 먼저 보고, 새 수업은 요청한 주제 → 반복 작업 → 최근 작업 → 일반 주제 순으로 고릅니다. 작업 근거와 선정 이유는 현재 작성자가 확인해 기록합니다.

코드·명령 수업은 개념별로 역할·흐름 이해 → 결과 예측 → 조건 변경 적용으로 깊어집니다. 해당 단계에서 도움 없이 설명할 수 있었다는 자기 평가가 서로 다른 이전 응답일에 두 번 이어지면 다음 단계의 질문을 제안합니다. 읽기·도움 사용·다시 보기·일부 설명 기록은 이 횟수를 다시 시작합니다. 같은 날 설명 공개 뒤의 추가 연습은 독립 답변으로 포함하지 않습니다. 숙련도 판정이나 자동 채점은 아닙니다.

처음 보는 내용은 설명부터 읽을 수 있고, 다른 질문은 선택해서 더 풀 수 있습니다. 현재 복습 간격은 자기 평가에 따라 1·3·7·21일을 쓰는 초기 규칙입니다. 질문 수와 간격이 학습 효과를 입증한 최적값은 아닙니다. 기존 텍스트 수업은 저장된 질문 순환을 유지합니다.

수업과 출처는 어떻게 준비되나요?

현재는 업무 기록과 공식 자료를 함께 확인해 작성한 수업 파일을 직접 가져옵니다. 각 수업의 선정 이유와 검토 주체를 표시하며, 업무에서 사용했다는 사실만으로 이해가 부족하다고 판단하지 않습니다.

자료의 원문 위치, 확인 날짜, 적용 버전과 발췌·요약을 수업에 보존합니다. 자료가 바뀌어도 자동 갱신되지 않습니다. 새로 검토한 수업을 가져오면 새 판본으로 보관하고, 이전 답변과 당시의 근거도 남깁니다.

수업과 출처의 추가·수정은 현재 수업 파일 가져오기로 제공합니다. 이 화면에서는 수업을 읽고, 미루거나 숨긴 뒤 복원할 수 있습니다. 자동 출제와 원문 변경 감지는 아직 연결되어 있지 않습니다.

검토한 로컬 JSON 수업 파일을 아래 명령으로 가져옵니다. 파일 형식과 합성 예시는 프로젝트의 Work-Grounded Learning 문서에 있습니다.

localbrain learning import /path/to/lessons.json --reviewed
